# 样片说明

四条片都是「168 拍」完整格式的**切片**（18–19 拍，约 14–15 秒），只包含活封面/钩子 + 片名卡，用来验证视觉语言和钩子强度，不是完整的一期。

## 文件对应关系

| 源文件（`src/`） | 成片 | 说明 |
|---|---|---|
| `pilotA-fluency.html` | `试片A-看不见的学会.mp4` | 认知 · 流畅性错觉。两张纸卡 + 自评/实测四柱 |
| `pilotB-dunbar.html` | `试片B-一百五十.mp4` | 关系 · 邓巴数。四层同心圆 |
| `pilotC-birthday.html` | `试片C-v2-同一天生日.mp4` | 概率 · 生日悖论。**互动式开场：41 人 + 5%/90% 二选一 + 2 秒倒计时** |
| 同上的早期版本 | `试片C-同一天生日.mp4` | v1：23 人点阵，直接陈述结论，无下注环节 |

`src/lib.js` 是从 `skill/vibe-explainer-video/kit/lib.js` 复制来的，方便直接打开 HTML 预览。

## 看片时重点看什么

1. **第 0 帧能不能直接当封面**：三条都是「左侧大字 + 右侧主角物件已经在画面里」。
2. **钩子有没有在 3 秒内落下反常识**：v1 是陈述，v2 是让你先下注再看答案。
3. **画面是"演"出来的还是"讲"出来的**：A 靠柱状反差（最弱，PPT 感最重）、B 靠圈层生长、C 靠点阵亮灭 + 红线穿人。
4. **减法**：C-v2 第二个反常识点靠「把 18 个人压暗」实现，不靠加注释。

## 已知取舍

- **A 片**的柱高是示意值，不是真实实验数据；上线前要么换成可核查研究，要么明确标「模拟」。
- **B 片**的 5/15/50/150 是邓巴数常见表述，圆圈直径为示意；150 有争议，不要讲成硬定律。
- **C 片**的 5% / 90% 是刻意的二选一：真实直觉区间在 5%–12%，给 5% 是为了制造下注欲。片中只说「答案是 90.3%」，不说「正确答案是 90%」。
- 选 **41 人**而不是 40 人：40 人是 89.1%，41 人才跨到 90.3%，「90%」这个选项才站得住。
